# AnswerCanvas 重播后暂停设计

## 目标

保留场景首次打开后的自动播放行为。用户点击“重播”时，将所有动态书写进度归零并停在时间轴开头；只有再次点击“继续”才开始播放。

## 状态转换

- 首次加载完成：`idle → playing`，行为不变。
- 播放中点击暂停：`playing → paused`，保留当前位置。
- 任意可操作状态点击重播：清零全部动态进度并进入 `paused`。
- 重播后点击继续：`paused → playing`，从第一个动态元素开始。
- 播放完成后点击重播：`complete → paused`，允许重新开始。
- 减少动态效果模式：仍直接显示完成态。

静态场景元素始终以完成态渲染，不受重播清零影响。

## 实现

在 `RecreationPlayer` 中增加 `reset()`：取消当前动画帧、重置索引、已用时间和完成回调标记，并向所有事件发送进度 `0`，但不播放或调度新帧。现有 `replay()` 复用 `reset()` 后继续调用 `play()`，以保持现有播放器 API 语义。

`RecreationStage` 的重播按钮改为调用 `reset()`、清空 React 进度并把状态设为 `paused`。主按钮随后显示“继续”，点击后调用 `resume()`。

## 验收

- 播放器 `reset()` 清零进度且不请求动画帧。
- reset 后 resume 从第一个事件开始。
- 点击重播后界面显示“继续”和“已暂停”。
- 首次加载仍自动播放。
- 播放完成后仍可重播到暂停状态。
- 全量测试、ESLint 和生产构建通过。
